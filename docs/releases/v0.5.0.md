# copilot-cli-relay v0.5.0

## Added

- Windows pilot support for local Codex chats in the unified ChatGPT desktop
  app, using the same Responses proxy as Codex CLI.
- A print/check-only PowerShell helper, `scripts/codex-desktop.ps1`, for a
  separate app provider, explicit model catalog, and HTTP/SSE transport.
  It does not write configuration, install software, or change permissions.
- Desktop setup and qualification guidance, updated README and architecture,
  and a glossary clarifying the supported app surface.

## Fixed

- SSE keepalives respect event boundaries, and upstream stream cleanup survives
  client cancellation and downstream send failures.
- Full-replay function/custom tool continuations retain their calls and results.
  Required tool choices are cleared when filtering leaves no tools.
- Diagnostic redaction fails closed at raw input limits, with bounded upstream
  error reads and static omission on redactor failure.
- Synthetic compaction rejects incomplete, malformed, or unusable summaries
  instead of reporting success.
- Malformed model catalogs return protocol-shaped errors and cannot produce
  misleading successful health counts.
- Relay-owned Claude headers are replaced case-insensitively.

## Upgrade

From the updated checkout, rebuild and recreate the relay:

```powershell
docker compose up -d --build proxy
```

For app setup, follow `docs/codex-desktop.md`. Preserve existing CLI providers
and merge the helper's output deliberately. Full access is not a relay routing
requirement.

## Validation and limits

- 478 Python tests, Ruff, 99% package coverage, and 38 PowerShell assertions pass.
  Offline wheel build, metadata, source-content, and isolated import checks pass.
- App support is a dated Windows pilot, not qualification of every OS, app
  version, or model. Only local Codex traffic is routed; ChatGPT Chat/Work,
  cloud tasks, voice, and plugin traffic are outside this integration.
- GUI follow-up, cancellation/recovery, and reopening remain unqualified.
  Post-hardening health and catalog checks passed; GUI inference was not repeated.
- Prompt pre-header disconnect detection and truncated-event recovery remain
  limited. The ordinary-summary fallback is not verified checkpoint/v2 compaction.
